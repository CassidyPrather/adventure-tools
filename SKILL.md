# adventure-tools

Unity 2022.3 project at the repository root (the "main project", which is the
dev harness) with redistributable VPM packages as directories under
`Packages/`. The VRChat SDK arrives through the vendored bootstrapper on first
editor open and never enters git. Code is AGPL-3.0-or-later with the
VRChat/Unity linking exception in `LICENSE_ADDENDUM`.

## Repo Map

- `Assets/` — the development harness project's own content; nothing shipped lives here.
- `Packages/net.wirenook.adventure-tools/` — the tools package; prefabs and animators are generated by `Editor/AdventureToolsBuild.cs`; see README.
- `Packages/net.wirenook.adventure-tools/Editor/PresenceBuild.cs`, `Presence.cs`, `PresenceCheck.cs` — the invisible switch (`Wirenook Unseen`) and presence (`Wirenook Presence`, `(Ghost)`): who sees and who hears the wearer, decided on each viewer's client. `Runtime/Core/PresenceModel.cs` is the rule in plain code, with tests in `Tests/Editor`; the generated animators are played against it by `Tools > Wirenook > Adventure Tools > Verify Presence`. Built on net.wirenook.selective-animation (`Selector`, `Circle`, `Audience`).
- `Packages/net.wirenook.adventure-tools/Editor/GameMasterBuild.cs` — the game master's kit (`Wirenook Game Master`), one prefab built from a list of tools (`IStageTool`: `DiceTool`, `PauseTool`, `ZoneTool`, `PointerTool`, `PortalTool`, `KeyTool`) that share a `Stage` (everything set down in the world, on one world-sync anchor bus), a `Pointer` (the finger's light, laser and ray) and two meshes made in code (`ShapeMesh`: one for every platform, one for PC's shaders). `Runtime/Core/GameMasterModel.cs` has the dice, the sizes and the key's traits in plain code, with tests; `GameMasterCheck` plays the generated animator as a wearer and a viewer (`Tools > Wirenook > Adventure Tools > Verify Game Master`). `Notices.cs` builds a set of screen notices from a list; there are two.
- `tools/notice_atlas.py`, `tools/stage_palette.py` — the cards and the signature mask the generators read. Run them after changing a list or the palette.
- `Packages/com.vrchat.core.bootstrap/` — VRChat's resolver bootstrapper, vendored byte-for-byte. Don't touch.
- `Packages/vpm-manifest.json` — the main project's VPM dependencies (by default the VRChat Avatars SDK, lilToon, and Modular Avatar; NDMF and `com.vrchat.base` are locked as their dependencies). MA and NDMF don't compile without the SDK, because it ships the `System.Collections.Immutable` and Harmony they use. Edit it with a VPM client (ALCOM / `vrc-get`), not by hand.
- `Packages/.gitignore` — allowlist inversion keeping resolver-installed packages out of git. Load-bearing.
- `ProjectSettings/` — pinned Unity project configuration (`ProjectVersion.txt` names the editor build).
- `scripts/` — the checks and builds; CI runs these same scripts, nothing else.
- `.github/workflows/ci-cd.yml` — lint-and-test on push/PR, package publish on release.
- `.githooks/pre-commit` — the fast checks; opt in with `git config core.hooksPath .githooks`.
- `Website/index.html` — placeholder package page; unthemed, unpublished, awaiting a future pass.
- `CREDITS.md` — intake ledger for everything third-party.

This repository is developed inside [cass-avatar](https://github.com/CassidyPrather/cass-avatar), which mounts it and its sibling packages as submodules under `modules/` and opens them all in one Unity project. Generated prefabs and animators are rebuilt from code (`Tools > Wirenook > ...`), never edited by hand.

## Commands

```bash

scripts/check-manifests.py     # package.json sanity across Packages/
scripts/format.sh --check      # dotnet-format over the CI-visible C#
scripts/test.sh                # headless NUnit run of Runtime/Core + Tests

```

## The SDK Boundary

- The VRChat SDK and Unity are proprietary; the repository must stay clonable,
  checkable, and testable without either installed.
- `Packages/*/Runtime/Core/` is engine-free C#. `scripts/test.sh` compiles it
  with plain dotnet against NUnit alone, so a `using UnityEngine` in Core is a
  CI failure, not a style nit. Engine and SDK glue lives outside Core and is
  exercised in the editor instead.
- Tests use classic NUnit asserts only: the same files must pass `dotnet test`
  and the editor's Test Runner, and the classic API is the overlap.
- Never weaken the `Packages/.gitignore` allowlist; it is what makes committing
  non-redistributable material structurally impossible.

## Presence Rules

- **Whether a renderer is enabled belongs to the invisible switch.** Its one layer animates a stand-in (`WirenookAvatarRenderers`, net.wirenook.assets) that the build spreads to every renderer. Another layer animating `m_Enabled` on a renderer would undo it there. Show and hide by scale.
- **Presence does not hide anything itself.** It writes `WN/Hidden`, `WN/Spectral` and `WN/Muted` by animation on each client, and the invisible switch's layer obeys the first. A feature with something that shows and is not a renderer (a light) reads `Presence.NotDrawnHere`.
- **The invisible switch's layer starts undrawn** (its "Loading" state, a tenth of a second) and presence's "Shown" layer starts in whatever a stranger gets under the settings the prefab loads with. Change either and a ghost flashes into view for everyone as it loads.
- **The spectre is two things**: `_WirenookSpectral` on Wirenook/lilToon through the stand-in for materials (PC), and a material swap to `Generated/spectre-mobile.mat` through the stand-in for renderers, marked for mobile only. A material swap that reached a PC build would stop Avatar Optimizer merging the avatar's meshes (measured: one skinned mesh became four).
- **The menu's choices are numbers from 1**, never synced, and the wearer's client turns each into two synced bits with a parameter driver. A menu switch turned off sets its number to 0; the "Keep" states put it back.
- **Moving the head needs `WirenookFreeHead` on the avatar's root.** Without it the build removes the mover (`WirenookBoneTarget`) and warns.

## Game Master Rules

- **A bone that carries shapes is reset before the mesh is bound** (`GameMasterBuild.Bone`). A rebuild finds the prefab as the last one left it, with bones resting at the scale their animator starts them at, which for most is nought; a mesh bound to a bone of no size is made of numbers that are not numbers.
- **What the kit leaves in the world is marked `WirenookApart`**, so the invisible switch and presence do not hide it. Anything of the wearer's own that is drawn through the kit's mesh (the key, the fingertip's light) has to narrow its audience with `Presence.DrawnHere` itself.
- **The kit's meshes are drawn through the stage's bounds** (`Stage.Reach`), which are a speck until a clip that shows something keeps them whole (`Stage.KeepDrawn`, which `Stage.Show` calls). A layer that shows a shape without it shows nothing.
- **A PC-only object must not carry a bone of the mesh every platform draws.** A mobile build removes the object and the mesh is left skinned to nothing. The key's contacts are under a PC-only object of their own for that reason; the check looks for it.
- **A thing is switched on for everyone only after the bus has read its new place out** (`Stage`, "Stage Publish"). Do not set a thing's "on" bit from anywhere else when it has just been moved: a viewer would be shown it where it used to stand.

## House Rules

- Every asset gets a `CREDITS.md` line at intake — source, author, license, URL. CC0 first.
- Nothing proprietary and nothing licence-incompatible enters this repository; generate or draw it instead.
- Unity editor stays on 2022.3.22f1, the version VRChat supports. Runtime Unity packages in `Packages/manifest.json` (Timeline, TextMeshPro, AI Navigation, uGUI) stay at the versions the VRChat client ships. Only editor-only tooling (IDE integrations, Test Framework) tracks the latest.
- Version lives in `package.json`; a release publishes every package whose version matches the tag.
- The linking exception in `LICENSE_ADDENDUM` is load-bearing legal text. Don't reword it casually.
- **A setting of something set down is its value on the stage, not a synced parameter** (`plan.Thing(name, value: ...)`, `thing.Value`, `kit.Stage.MenuValue`): the bus carries all of them for eight bits. The kit's four sizes were 32 bits and are now part of those eight.
- **A thing marked `rehearsed` is shown to `thing.Shown` and acts for `thing.Real` only.** Its contacts rest switched off and are switched on by a layer for `Real`; shown to the people backstage as a spectre, it must not be touchable by them.
- **A kit that replaces the plain kit keeps the prefix `GM`** (`GameMasterOptions.Replaces`): the replaced feature's parameters stay declared, and only names that coincide cost nothing twice.
